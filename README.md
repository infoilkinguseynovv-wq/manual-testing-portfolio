# Manual Testing Portfolio - SauceDemo

Bu layihə mənim **QA Manual Testing** bacarıqlarımı nümayiş etdirmək üçün hazırlanmışdır. Layihə çərçivəsində real bir veb-sayt (SauceDemo) üzərində test prosesi tətbiq olunub.

## 📁 Layihənin Strukturu
* **[Test Plan](./test-plan/README.md):** Testin məqsədi, mühiti və əhatə dairəsi.
* **[Test Cases](./test-cases/login_test_cases.md):** Login funksionallığı üçün hazırlanmış ssenarilər.
* **[Bug Reports](./bug-reports/login_error_report.md):** Tapılmış xətaların peşəkar sənədləşdirilməsi.
